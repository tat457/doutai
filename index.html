ゲーム仕様 & AR機能について

ARカメラモードの遊び方

  • カメラ許可を有効にすると、画面に映像が投影されます。
  • カメラに手をかざすと指先（人差し指など）にオーラエフェクトが表示されます。
  • 指先を画面内の光る点に重ねると消去できます！
  • 画面を直接タップ（クリック）してもいつでもプレイ可能です。

GitHub Pages公開手順

  1. このファイルを index.html としてリポジトリに保存
  2. GitHub リポジトリの Settings > Pages を開く
  3. Source を Deploy from a branch にし、main を選択
  4. 発行されたHTTPS対応URLからアクセス（カメラ利用にはHTTPS接続が必須です）
