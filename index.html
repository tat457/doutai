ゲームについて & GitHub公開方法

遊び方

  • 画面内に一瞬出現する「光る点」を指やマウスで素早くタッチします。
  • 連続で成功するとコンボが繋がり、スコア倍率がアップします。
  • お手つき（何もない場所のタップ）やターゲットの消滅はコンボが切れる原因になります。

GitHub Pagesで即時無料公開する手順

  1. GitHubで新規リポジトリを作成（例: dynamic-vision-game）
  2. このコードを index.html という名前で保存してコミット&プッシュ
  3. リポジトリの Settings > Pages を開く
  4. Source を Deploy from a branch に設定し、main (または master) ブランチを選択して Save
  5. 数分後に発行されるURLにアクセスするだけで誰でもWebでプレイ可能！
